## Featured Projects / 代表项目

### [CleanHelper 大黄清理大师](https://github.com/uangh66/CleanHelper)

一个基于 **C# WPF + .NET 8** 开发的 Windows 桌面端清理工具，支持临时文件扫描、风险分级、选择清理、日志记录、报告导出、空间体检和聊天缓存分析。

A Windows desktop cleaner built with **C# WPF and .NET 8**, featuring safe temp-file scanning, risk grading, reports, and cache analysis.

### [Terminal GIF Player](https://github.com/uangh66/terminal-gif-player)

一个基于 **PowerShell** 的 Windows 终端 GIF 播放器，支持 ANSI 24-bit 真彩色渲染、LRC 歌词同步、滚动字幕、标题轮播和 INI 配置。

A PowerShell terminal GIF player with ANSI true-color rendering, LRC lyrics sync, marquee text, title rotation, and INI configuration.
